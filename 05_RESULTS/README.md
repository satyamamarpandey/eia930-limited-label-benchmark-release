# 05_RESULTS: authoritative experimental outputs (protocol v1.1)

| Path | Content |
|---|---|
| `final/run_manifest.json` | Run record: 625 cells, 0 errors, input and configuration SHA-256, software versions, counts per variant |
| `final/raw/runs_*.csv` | Raw per-run results, one file per variant (8,750 rows in all; 2,125 primary) |
| `final/raw/event_detections_*.csv` | Per-event detection records |
| `final/raw/injection_ground_truth.csv` | Injection ledger (4,125 events; 1,375 at the primary contamination level, 375 in test). "Ground truth" refers to the controlled injections only |
| `final/raw/scores/*.npz` | 125 score files (3,250 arrays) of the primary variant |
| `final/tables/*.csv` | Model evaluation summaries, paired statistical comparisons, ablations, missingness effects, post-hoc difference-in-differences, error analysis |
| `final/key_numbers.json` | Every number quoted in the paper (972 top-level keys) |
| `final/exploratory/` | Post-hoc exploratory SWPP refit |
| `figures/` | Publication figures (PDF, PNG) and the data behind each figure (`*_data.csv`) |

`final/raw/` and `final/run_manifest.json` are never modified by any script. Their SHA-256 values match those recorded when the run finished (2026-10-22; checked by `tests/test_experiment.py::test_final_raw_outputs_match_recorded_checksums`). Everything else is regenerated byte-identically by `07_REPRODUCTION/verify_all.ps1`. `MANIFEST_SHA256.txt` in the project root lists every file.

Three figure-data files are copies of tables by design (`fig_ap_per_authority_data.csv` = `table_per_ba_none.csv`, `fig_event_detection_family_tier_data.csv` = `table_event_family_tier_none.csv`, `fig_ap_missingness_data.csv` = `table_by_condition.csv`); `make_figures.py` writes the data next to each figure for auditing. The four figures used in the paper are also in `02_MANUSCRIPT_SOURCE/figures/` (byte-identical copies, required to compile the manuscript there).

Reproduction runs and the resumption test write temporary folders here (`_reproduction_run/`, `_resumption_test/`); they are deleted after the comparison.

The v1.0 run, development runs and earlier reruns are in `06_AUDIT/historical_evidence/`.
